# dailyclaimit-home

Static site for dailyclaimit.com. Edit `offers.json` / `content/guides/*.html`, then run
`python3 scripts/build.py` and commit the generated output. Push to `main` deploys via GitHub Pages.

## Offer compliance fields

Each offer in `offers.json` has:

- `allowed_traffic`: traffic types the network/advertiser permits (Contextual, Display, Search, Social, Native, Mobile Ads, Email).
- `restrictions`: short note on creative/traffic restrictions.

Everything on this site (cards, guide text links, CTA buttons) counts as **Contextual** traffic.
`build.py` refuses to build if an `active` offer's `allowed_traffic` does not include `Contextual`.
Do not use offers on Pinterest/social or email unless `allowed_traffic` includes Social / Email.

## Lead magnet: Paid Quiz & Survey Starter Kit

- PDF: `downloads/paid-quiz-survey-starter-kit.pdf` → https://dailyclaimit.com/downloads/paid-quiz-survey-starter-kit.pdf
- Generated by `python3 scripts/build_starter_kit.py` (headless Chrome) from active `surveys-quizzes` offers in `offers.json`.
  **Re-run it whenever those offers change** so the PDF links stay current. Disclosure is only at the bottom of page 2.
- Signup box: `kit_block()` in `build.py`. Shows on `/surveys-quizzes/` and any guide containing `<!--starterkit-->`.
- Submission: `assets/site.js` posts to the same Apps Script endpoint as the Daily Drop form:
  `{"email", "timestamp", "source": "dailyclaimit-starter_kit-<page slug>"}`. On send, the form hides and a download button appears.
